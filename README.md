# Container ID Recognition System (YOLO + CRNN)

An end-to-end Computer Vision and Optical Character Recognition (OCR) pipeline designed to automatically detect, extract, and recognize shipping container identification codes from natural scene images. This project replaces traditional OCR engines (like Tesseract) with a custom deep-learning approach utilizing YOLO for text localization and a CRNN (Convolutional Recurrent Neural Network) for sequence recognition.
